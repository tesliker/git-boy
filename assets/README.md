# Git Boy materials

Original assets generated October 22, 2026 for this project using the built-in image-generation tool. No source photograph, Nintendo artwork, logo, or proprietary game asset was copied. The supplied console photographs informed the material and layout brief only.

- `console-plastic.png`: subtle seamless warm-gray ABS micrograin, flat diffuse lighting, no marks or objects; multiplied at low opacity over native shell lighting.
- `control-dpad.png`: orthographic matte charcoal directional cross, recessed circular thumb center, worn soft edges, warm-gray circular mounting socket, transparent surrounding background, top-left light.
- `control-action.png`: orthographic burgundy ABS circular action button, softly worn matte face, warm-gray mounting socket, transparent surrounding background, top-left light.
- `control-pill.png`: orthographic horizontal dark-gray silicone capsule button in an ivory-gray recessed socket, transparent surrounding background, realistic matte rubber texture.

The controls were generated as separate transparent PNGs, copied unchanged into this project, and scaled by the native renderer. Labels are native text underneath the assets; animated click depression remains interactive. The original generated files remain under the Codex generated-images folder.

The initial Higgsfield `nano_banana_2_1` request used the explicitly requested free unlimited option. Higgsfield returned: "Unlimited generations aren't supported for nano_banana_2_1." No job or paid retry was submitted through Higgsfield. The built-in image-generation tool produced the final assets.
